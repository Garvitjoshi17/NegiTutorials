NEGI TUTORIALS - HTML / CSS / JS

No Node.js, npm, React or Vite is required.

FILES
- index.html  -> website markup
- style.css   -> all styling and responsive design
- script.js   -> menu, smooth scrolling, header effect and form validation
- images/     -> logo
- favicon.svg -> favicon

RUN
1. Open this folder in VS Code.
2. Open index.html in a browser.
3. Recommended: install the VS Code extension "Live Server" and choose "Open with Live Server".

The contact form is intentionally a front-end preview and does not send/store messages.
